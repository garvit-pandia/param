# Image credits

Every picture on the site is listed here with where it came from and its licence. All of them are released under CC0 (public domain dedication), which allows commercial use without asking permission or giving credit. The credit below is kept anyway so each file can be traced back to its source.

The files live in `images/` and are wired up in `data/images.ts`.

## 3D icons (`images/3d/`)

All from **3dicons** by Vijay Verma (https://3dicons.co, source at https://github.com/realvjy/3dicons), "gradient" style, "dynamic" angle. Licence: CC0 1.0. The site shifts their colour towards blue with a CSS filter (`.icon3d` in `app/globals.css`); the files themselves are unchanged.

`chat-bubble`, `computer`, `file-text`, `flash`, `lock`, `paint-kit`, `rocket`, `rupee`, `shield` (named `sheild` at the source), `thumb-up`.
